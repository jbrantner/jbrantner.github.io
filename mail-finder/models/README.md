Text reader models used by Mail Finder's "Sharper" reader.

- det.onnx: PP-OCRv3 mobile text detection
- rec.onnx + dict.txt: PP-OCRv5 English text recognition

From PaddleOCR (https://github.com/PaddlePaddle/PaddleOCR), Apache License 2.0,
ONNX conversions from https://huggingface.co/monkt/paddleocr-onnx (Apache 2.0).
