Setup on the render computer

  
    
    
  1. Install Tailscale on the render computer and on your iPhone, and sign in to the same account on both.
    2. 
    
  2. In the Tailscale admin page, under DNS, turn on MagicDNS and HTTPS certificates.
    3. 
    
  3. Start ComfyUI with these flags:
    --enable-cors-header "*" --preview-method auto
    The first lets this app talk to it; the second gives live previews while it paints.
    4. 
    
  4. On the render computer, run once:
    tailscale serve --bg 8188
    It prints an address like https://render.tail1234.ts.net. Paste that above and tap Connect.
    5. 
    
  5. Keep Tailscale switched on on the phone. It works from the couch or from work.
    6. 
  

  
Why the extra step: this app lives on an https page, and iPhones block https pages from talking to a plain http address. Tailscale Serve gives ComfyUI a private https address only your devices can reach. On the same computer as ComfyUI you can also use http://127.0.0.1:8188 in a desktop browser.
