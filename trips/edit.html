Edit Trips

Changes show on everyone's Trip Status page a minute or two after you save.

Connect this phone once

This page saves to your GitHub site, so it needs a key from your GitHub account. The key stays on this phone only.

  1. Open GitHub's new token page.
  2. Name it "Trip Status". Pick an expiration (up to a year).
  3. Under Repository access, choose "Only select repositories" and pick jbrantner.github.io.
  4. Under Permissions, set Contents to "Read and write".
  5. Tap Generate, copy the key, and paste it below.

Past trips drop off when you save. Only the date, time and status are stored, so don't type anything else here.
